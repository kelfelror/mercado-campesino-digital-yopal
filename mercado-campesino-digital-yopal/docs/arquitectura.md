# Arquitectura propuesta
1. Presentación: HTML, CSS y JavaScript responsive.
2. Negocio: API REST con Java y Spring Boot.
3. Datos: PostgreSQL.

El frontend es un prototipo con datos ficticios. El backend expone un endpoint de estado y una clase de validación de inventario con pruebas. Autenticación, persistencia, reportes e integración transaccional de reservas siguen pendientes.
